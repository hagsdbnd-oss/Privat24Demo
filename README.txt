PRIVAT24 DEMO — Android Studio project

This is an offline, standalone demonstration app. It is NOT PrivatBank software,
not connected to any bank, and cannot access accounts or make payments. The DEMO
label is intentionally visible in the interface.

HOW TO BUILD THE APK
1. Install Android Studio on a computer.
2. Open the folder Privat24Demo in Android Studio.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK; use Locate to find it.

The APK output is normally app/build/outputs/apk/debug/app-debug.apk.
This project is configured for offline app operation after installation.
